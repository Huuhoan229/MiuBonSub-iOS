# Agent Notes - MiuBonSub-iOS

MiuBonSub-iOS is the iOS client for the MiuBon Vietsub backend. It uses
Capacitor with app id `com.miubon.vietsub.vip`, app name `MiuBon Vietsub`, and
`webDir` set to `www`.

## Main Areas

- `ios/App/App/`: native iOS shell files, including `NativeApp.swift`,
  `AppDelegate.swift`, `Info.plist`, storyboard and assets.
- `www/`: bundled web UI and helper scripts copied into the iOS app.
- `capacitor.config.json`: Capacitor app id/name/web directory.
- `NATIVE_IOS_README.md`: native iOS goals and TrollStore build instructions.
- `MBV_Full_Feature_Map.md`: backend/API and iOS tab mapping.
- `build_trollstore_ipa.sh`: macOS build helper for TrollStore IPA.
- `old_app.swift`, `uploads_view.swift`, `update_ui*.py`: migration/reference
  and patch helper files.

## App Behavior

The app is a controller/monitor for the desktop backend. Heavy work remains on
the backend machine: scraping, ffmpeg, STT/TTS/translation, and uploads. First
run asks for a backend URL such as `http://LAN_IP:2209` or a public tunnel URL.

## Current Native Feature Sync

- `ios/App/App/NativeApp.swift` owns the native controller UI. Keep the Uploads
  tab synced with the backend upload queue contract instead of using the older
  YouTube-only helper file at the repo root.
- Upload queue control uses `GET/POST /api/upload-queues/control` and queue
  status endpoints `/api/youtube/queue`, `/api/tiktok/queue`, and
  `/api/facebook/queue`. The iOS tab defaults to YouTube but must preserve
  switching to TikTok and Facebook.
- iOS can enable/disable and pause/resume upload queues, but actual upload
  workers stay on the backend PC. Do not add uploader worker execution to iOS.
- When iOS runs AI grouped series, save URLs through `/api/series/save-urls`
  so the series library can later resume with the saved URL/context registry.
- The bundled web UI and native video player must not point media elements at
  the static frontend host. Use `apiAssetUrl(projectApiPath(...))` in
  `www/static/js/app.js`; native `NativeApp.swift` normalizes accidental
  `tool.miubon.xyz`/`miubon.xyz` backend entries to
  `https://api-mbvietsub.miubon.xyz` for API/media calls.
- iOS video playback should target the 720p web preview stream
  (`/api/project/<id>/stream/preview`, backed by `final_video_preview.mp4`),
  not the full render.

## Build Notes

- Run `npm ci` when dependencies need refresh.
- Run `npx cap sync ios` after changing the web bundle or Capacitor config.
- Build IPA on macOS/Xcode with `bash build_trollstore_ipa.sh`.
